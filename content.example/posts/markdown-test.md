这篇文章不讲道理，只负责把各种 Markdown 语法都用一遍，让阅读页的每一种排版都有机会出场。读的时候留意左边标示线上的目录：一级标题（比如文末的「附录」）的三角最大，三级最小，**四级标题不进目录**；当前在屏幕里的小节会亮起来。

## 一、文字与强调

普通段落是正文字体。中文和 English 混排时，汉字用中文字体，Latin letters 用西文字体，数字 0123456789 在正文里跟着中文字体走。

行内可以有 **粗体**、*斜体*、***粗斜体***、~~删除线~~、`行内代码` 和 [一个链接](https://example.com)。也可以把它们叠在一起：**这是粗体里的 `code` 和 [链接](https://example.com)**。

这是一段很长的段落，用来检查行高、字距和两端的留白是否舒服。阅读页的正文栏宽度大约是七百二十像素，中文一行三十多个字，太宽眼睛要来回扫，太窄又会频繁换行；这里尽量让一行的长度接近一口气能读完的长度。段落之间留出一行左右的空白，标题前面留得更多，让结构一眼可见。

## 四、代码

行内代码用等宽字体：`const answer = 42;`。代码块也是等宽字体，不加框：

```ts
// 一段 TypeScript：按速度规则走的小车
function step(p: number, v: number, target: number, dt: number) {
	const dist = target - p;
	const want = Math.sign(dist) * Math.min(VMAX, Math.sqrt(2 * ACC * Math.abs(dist)));
	v += (want - v) * (1 - Math.exp(-dt / TAU));
	return { p: p + v * dt, v };
}
```

## 七、脚注与缩写

这句话后面有一个脚注[^1]，这句也有[^note]。

[^1]: 第一个脚注的内容。
[^note]: 第二个脚注，可以写得长一些，看看脚注区的排版：它在文章最后，字号小一号。

## 七½、折叠块

用三个冒号包起来就是一个折叠块，方括号里是标题，点标题展开或收起：

```md
:::fold[点我展开]
折起来的内容。
:::
```

:::fold[点我展开]
折起来的内容，可以是任何 markdown：**加粗**、`代码`、列表——

- 第一项
- 第二项

> 引用也行。
:::

标题后面加 `{open}` 就默认展开：

:::fold[默认展开的一块]{open}
这一块一打开文章就是展开的。
:::

嵌套时外层多写一个冒号：

::::fold[外层]
外层的内容。

:::fold[内层]
内层的内容。
:::
::::

正文里普通的冒号不受影响，比如时间 12:30、比例 16:9，或者「注意:这不是指令」。
