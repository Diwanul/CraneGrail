# 阅读页的样子

这是一篇演示文章，用来检查阅读模式下的排版：正文在标示线右边，目录挂在线上，读到哪一节，线上对应的三角就会变大。

## 第一节：为什么要在主页里读

从主页点进文章时，背景、banner、头像和标示线都留在原地，只有内容区换掉。这样从列表到正文是连续的，不像换了一个网站。

地址栏会变成这篇文章自己的地址，所以刷新、分享链接、搜索引擎看到的都是同一篇文章的独立页面，布局和这里一样。

## 第二节：引用和代码

> 不是所有流浪的人都迷失了方向。
> Not all those who wander are lost.

代码块上下各有一个角：

```js
function greet(name) {
	return `Hello, ${name}`;
}
```

### 一个小节下面的小节

小节标题在目录里会缩小一号，挂在线上的三角也更小。

#### 第四级标题不进目录

太细的层级不挂到线上。

## 第三节：列表

- 收文章卡片
- 章节行淡出
- 标示线不动
- 正文淡入，目录挂到线上

后退、Esc 或者点头像，会倒着放回主页，回到原来的章节和选中项。

## 第四节：结尾

再多写几段，好让页面能滚起来。

正文用正文字体，标题用标题字体。中文模式下中西文自动混排；英文模式下整段用西文字体。

如果文章没有小节标题，线上就不挂目录，只剩一根线。

最后这一段只是为了让最后一节也能滚到视口上方，看目录切换到这一节时的样子。
